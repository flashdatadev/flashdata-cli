# v1.0.0 release, installation and source builds

[FlashData](https://flashdata.dev) · [API documentation](https://flashdata.dev/docs)

[The official source repository](https://github.com/flashdatadev/flashdata-cli) is public. The `v1.0.0` source tag identifies this version; its [formal GitHub Release](https://github.com/flashdatadev/flashdata-cli/releases/tag/v1.0.0) provides public binary downloads, release notes and checksums. See the [installation guide](installation.md) or [简体中文](installation.zh-CN.md). Build from a normal clone with `go mod download` and `go build ./cmd/flashdata`. No sibling SDK checkout is required.

The [official Homebrew tap](https://github.com/flashdatadev/homebrew-tap) distributes these same checked release binaries to Linux and macOS: `brew install flashdatadev/tap/flashdata`. The formula pins all four platform archive checksums. Publish and test a new stable CLI release first, then update the tap's version, URLs and SHA-256 values; its CI verifies every archive and tests native installation, offline commands, reinstall and uninstall. Users upgrade with `brew update` and `brew upgrade flashdatadev/tap/flashdata`. No Homebrew signup or separate package upload is needed. Keep released archives unchanged after a formula references them.

The [signed APT repository](https://github.com/flashdatadev/apt) serves `https://flashdatadev.github.io/apt/`, suite `stable`, component `main`, for Ubuntu 22.04/24.04 and Debian 12/13 on amd64/arm64. Debian package `1.0.0-1` preserves the v1.0.0 executable. Its main-only signing environment contains only the signing subkey and passphrase; the certification primary key stays out of CI. InRelease/Release.gpg authenticate the package indexes and checksums. See the [English setup](installation.md#apt-ubuntu-and-debian), [简体中文](installation.zh-CN.md#aptubuntu-和-debian), and [APT maintenance guide](https://github.com/flashdatadev/apt/blob/main/docs/maintaining.md). Publish new Debian revisions for packaging corrections and keep existing versioned packages unchanged. The APT workflow tests installation and upgrades on both architectures before deploying and against the published HTTPS endpoint. Metadata expires after 30 days and is refreshed weekly; monitor workflow failures and key expiry.

The [signed RPM repository](https://github.com/flashdatadev/rpm) serves `https://flashdatadev.github.io/rpm/`, channel `stable`, for x86_64/aarch64. RPM `1.0.0-1` preserves the v1.0.0 executable. A dedicated RSA-4096 signing subkey signs each RPM and repository metadata with SHA-256; CI keeps the certification primary out of the main-only signing environment. Ten candidate tests cover Fedora 43/44 and RHEL 8/9/10 userspace (Red Hat UBI) on both CPUs before deployment, followed by ten public HTTPS tests of the exact documented installer. A signed, test-only `1.0.0-0.upgradetest` package exercises upgrade ordering; it is never publicly indexed. See [English setup](installation.md#rpm-fedora-and-rhel), [简体中文](installation.zh-CN.md#rpmfedora-和-rhel) and [RPM maintenance](https://github.com/flashdatadev/rpm/blob/main/docs/maintaining.md). Keep published RPM bytes/signatures immutable; increment the packaging release for corrections. Rotate the two-year certificate before expiry, monitor weekly CI and preserve the protected primary-key backup. RPM metadata cache expiry is not a signed replay-prevention guarantee.

The SDK dependency is pinned to the public **v1.0.0** tag in go.mod. Go validates the recorded go.sum checksums. CI checks out only this repository and tests the resolved dependency; it does not silently use the sibling SDK's current working tree. Local SDK changes can be tested intentionally with a go.work workspace, outside a release build.

Run `python scripts/build_release.py --go /absolute/path/to/go --commit <full-40-character-Git-commit>` from a clean checkout of the intended tag to build five CGo-disabled executables and archives with reviewed docs, examples, license notices and metadata. The script resolves the exact SDK module into Go's module cache and rejects a local module replacement. Executables embed that exact commit in `--version`. Reports retain the commit, CLI/SDK runtime source hashes, SDK version/checksum and Go toolchain; archive paths are portable filenames relative to the report. The script copies the versioned release notes to `RELEASE_NOTES.md`, and `SHA256SUMS` covers all archives, the report and release notes. No upload, tag or release is created by this script.

`release-files.json` selects runtime package files. ZIP and tar metadata are normalized, and SHA256SUMS records archive checksums. Package-policy tests run with `python -m unittest discover -s scripts -p "test_*.py"`. Before distributing binaries, inspect the contents and verify the checksums. Place the matching executable in a user-controlled PATH directory and check --version/--help offline. Installed binaries require no separate runtime.

[GitHub Actions](https://github.com/flashdatadev/flashdata-cli/actions) covers Linux, Windows and native Intel macOS with Go 1.25/1.27, Apple Silicon cross-builds on both Go versions, Linux race checks, package-policy regressions and five-platform archive builds. Native Apple Silicon execution, real Secret Service/Keychain behavior, production service availability, signing and macOS notarization remain separate validation tasks. Intel macOS runners are pinned to `macos-15-intel`; the Apple Silicon hosted-runner jobs remained unassigned before test execution. Superseded CI runs are cancelled automatically. SDK v1.0.0 is the dependency for this tagged CLI version. The formal release includes packages, [release notes](release-notes-1.0.0.md), current READMEs, a build report and SHA256SUMS. Public source tags can also be resolved through Go tooling.

The published v1.0.0 binaries retain the exact bytes and source commit verified before publication. Package documentation was finalized afterward; `documentationCommit` in the release build report identifies that separate documentation snapshot. The tag and SDK dependency remain fixed, and the report records a SHA-256 hash for each preserved executable. Archive checksums were refreshed after packaging the updated docs.

Python installer support is prepared as five platform-specific `flashdata-cli` 1.0.0 wheels, preserving the exact published v1.0.0 executables. Source and candidate-test workflows are on GitHub; no PyPI/TestPyPI upload has been performed for this candidate. See [English wheel preparation](python-packaging.md) / [简体中文](python-packaging.zh-CN.md) for pinned assets, checksums, native pip/uv tests, compatibility and the remaining native-host publication checks.
